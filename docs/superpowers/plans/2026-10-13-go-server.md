# Go Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Crear un servidor personal administrable desde móvil, portable de Android/Termux a Linux/VPS y con actualización/sincronización automática.

**Architecture:** Node.js sin dependencias runtime para máxima portabilidad, panel PWA servido por el mismo proceso, scripts shell para instalación/actualización y Git como capa de sincronización. La seguridad remota se delega a VPN/Tailscale y autenticación por token en operaciones administrativas.

**Tech Stack:** Node.js 20+, Git, PM2, Termux/Linux, GitHub Actions.

**Spec:** README.md

## Global Constraints
- Debe poder operarse desde un dispositivo móvil.
- Debe soportar Android/Termux y migración a Linux/VPS.
- Debe actualizarse automáticamente desde Git.
- No se guardan secretos en el repositorio.

## Review Focus
- Token administrativo vacío debe denegar acceso.
- Fallos de Git no deben tumbar el panel.
- Auto-update debe ser idempotente.
- Repos sin remoto deben omitirse sin detener los demás.
- La interfaz debe ser utilizable en viewport móvil.
